# Consistency read: changes

- Signpost sentence ("The point to hold on to is that the steam does not push."): now "The steam, then, does not push."
- Voice drift, imperatives: "Notice what a horse is. It is a machine..." now "A horse, after all, is a machine..."; "Step back from the mine, and that is true of..." now "Beyond the mine, the same was true of...". The other imperatives ("Imagine...", "Follow a single thread...", "Stand in Manchester...") are left; the style sheet allows "Imagine" and an occasional "you".
- Thread dropped (chapter 53 says the sugar islands had factories a century before the first cotton mill): added after the Cromford pattern "The sugar islands had run their slaves to the clock in the same way a century before; Cromford did it with free workers in England." Also "But Cromford set the pattern" now "Even so, Cromford set the pattern".

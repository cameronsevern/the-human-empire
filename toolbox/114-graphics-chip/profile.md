# The graphics chip

| | |
|---|---|
| **First made** | Nvidia's GeForce 256, California, 1999, sold as the first "GPU" |
| **Made of** | One large silicon chip, with memory chips, on a board with fans |
| **What it does** | Does thousands of simple multiplications at the same moment |
| **Before it** | 3D cards that left the geometry sums to the main processor |
| **After it** | Google's TPU, in use from 2015, built only for neural networks |

## Why it mattered

A video game has to work out the colour of every dot on the screen, two million or more of them, sixty times a second, and each by much the same sums. A graphics chip was therefore built from a great many small, simple workers instead of a few clever ones. In 2007 Nvidia released a way to program its chips for any sums at all, and scientists soon found that the arithmetic of a neural network fitted them well.

From 2017, Nvidia's chips added units that multiply whole small grids of numbers in a single step. The H100, of 2022, holds 80 billion transistors and can draw 700 watts on its own.

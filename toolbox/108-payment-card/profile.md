# The payment card

| | |
|---|---|
| **First made** | Cardboard in 1950; IBM added the magnetic stripe in 1969 |
| **Made of** | Plastic, a stripe of magnetic oxide, and now a chip and aerial |
| **What it does** | Names an account, so a shop can ask the bank to pay |
| **Before it** | Metal charge plates, each issued by one shop to its customers |
| **After it** | Telephones that pay with a stand-in number, such as Apple Pay, 2014 |

## Why it mattered

Every card is the same size, 85.6 by 54 millimetres, so any machine in the world can take it. The last digit of the number is a check, worked out from all the others, so a number with one digit wrong fails at once. The stripe, however, was easy to copy. Anyone with a cheap reader could lift what it held and write it onto a blank card.

The chip ended most of that, because for each payment it works out a fresh code that a copy cannot produce. Britain moved to chips in the mid-2000s. Fraudsters went on copying stripes for use abroad, but by 2019 British losses to forged cards were 92 per cent below their peak.
